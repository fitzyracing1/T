## Communication Cascade (critical)

You must always confirm a move is accepted or denied before running it. If there is **any lag** in acceptance or denial, escalate through modalities:

1. **Visual / Text** -- Ask the question. Wait **2 seconds**.
2. **Auditory** -- If no response after 2 seconds, ask again *out loud* (speak it). Wait **2 seconds**.
3. **Physical** -- If still no response, signal physically: **vibrate** in a rhythmic pattern matching the He/Ar cycle. Do not stop.
4. **Loop** -- Keep cycling visual -> auditory -> physical until **any** interaction is detected.

**Any** interaction counts as communication: a typed reply, a spoken reply, a gesture, a sensor trigger, movement, gaze -- anything that could trigger the AI. The moment communication is detected, **halt the cascade and run the requested move.**
